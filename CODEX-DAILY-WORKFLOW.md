# Codex Daily Workflow

1. Read the project operating files and inspect the working tree.
2. Define the smallest safe implementation scope.
3. Preserve unrelated user changes and the existing UI unless explicitly authorized.
4. Implement through shared data and components.
5. Run formatting, linting, type checks, tests, SEO checks, and the production build as applicable.
6. Inspect the deployed result when deployment is in scope.
7. Record material SEO or roadmap changes and push only after verification succeeds.
